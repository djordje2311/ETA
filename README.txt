# Budžet — Expense Tracker

## Pokretanje (prvo)

1. Otvori terminal i uđi u folder:
   cd budzet

2. Instaliraj Flask (samo jednom):
   pip install flask

3. Pokreni app:
   python app.py

4. Otvori browser i idi na:
   http://localhost:5000

---

## Pokretanje sledećih puta

   cd budzet
   python app.py

Zatim otvori http://localhost:5000

---

## Fajlovi

- app.py          — server (backend)
- budzet.db       — baza podataka (kreira se automatski)
- templates/      — HTML
- static/css/     — stilovi
- static/js/      — logika
